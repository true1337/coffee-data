# Данные для «Мастер кофемашин»

Приложение скачивает отсюда `manifest.json` и `data.json` по свайпу вниз на главной.

## Как обновить данные
1. Правишь `data.json` (модели в `models`, ошибки и поломки в `families`).
2. Запускаешь `python make_manifest.py` — он проверит файл и пересчитает контрольную сумму.
3. `git add . && git commit -m "обновил данные" && git push`
4. В приложении тянешь главный экран вниз.

GitHub раздаёт файлы с кэшем до ~5 минут. Если приложение пишет «Контрольная сумма не сошлась», значит сервер ещё отдаёт старый data.json — подожди и повтори.

## Адрес для приложения
`https://raw.githubusercontent.com/ЛОГИН/coffee-data/main/` → вставить в `DataConfig.BASE_URL`.
